## The joke

> My son asked why I always bring a ladder to the barbecue. I said, "Son, someone has to raise the steaks."

One original dad joke: a father at the barbecue, a ladder, and a clean pun on "raise the stakes" that lands on "steaks" — punchline at the end, spoken rhythm a dad could deliver across the dinner table.

## How to run

```sh
python3 main.py
```

This writes the joke (105 characters, no trailing newline) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. Python 3.13 standard library only, no network, fully deterministic — every run writes the exact same text.
